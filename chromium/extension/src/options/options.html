Privacy

Nothing leaves your computer. No servers, accounts, analytics or network code. Settings stay on this device.

Chrome calls the site access “read and change all your data”. Cloak Desk reads page text only to cover it, and never stores or changes it.

What it can't cover

  • Chrome's own interface, chrome:// pages and the Web Store
  • Text in images, video, PDFs and canvas apps like Google Docs
  • Matches highlighted by Find (Ctrl+F)
  • Other desktop apps. Cloak Desk for Windows covers those.
